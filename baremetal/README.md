# SPC-1000 Baremetal Emulator (`baremetal`)

본 디렉토리는 OS(Operating System) 없이 라즈베리 파이(Raspberry Pi 1, Zero 등)에서 직접 구동되는 **SPC-1000 베어메탈 에뮬레이터** 프로젝트입니다. Circle 프레임워크를 기반으로 하며, SD 카드 파일 시스템 연동, USB 키보드 입력, 화면 출력, PSG 사운드 렌더링 및 카세트 테이프 초고속 로딩(Turbo Load) 등을 지원합니다.

---

## 🛠 현재까지의 구현 내용 (Implementation Highlights)

### 1. 카세트 테이프(TAP) 로딩 및 정합성 보정
*   **비트 싱크 오프셋 보정 (+10 Offset)**:
    *   싱크 신호(`11000000`) 검출 이후의 시작 비트(`1`) 정합성을 위해 데이터 필드 판정 오프셋을 `scan_pos + 8`에서 `scan_pos + 10`으로 보정했습니다.
    *   이로써 `CLOAD0`가 실제 스타트 비트를 올바르게 소모하고, `VBLOAD` 페이즈가 정확한 비트 정렬 상태로 데이터를 읽을 수 있도록 수정했습니다.

### 2. 하드웨어 리셋 및 시스템 안정화
*   **키보드 단축키 RESET 지원**:
    *   `F10` 또는 `F12` 키를 누르면 시스템 리셋 플래그(`g_reset_requested`)가 활성화됩니다.
    *   리셋 시 `spcsys.IPLK=1`, `GMODE=0`, `psgRegNum=0`, cassette 상태 초기화, Z80 리셋, PSG 리셋을 수행하여 안정적인 웜 리셋을 보장합니다.
    *   `rewind_on_reset=1` 설정 시 테이프 위치를 처음으로 되감습니다.
*   **Host 빌드 RESET 키 전달 버그 수정**:
    *   Host 빌드에서는 USB 키보드 장치(`g_pKeyboardDevice`)가 `nullptr`이므로 `HostUpdate()`의 F10/F12 키 상태가 `KeyStatusHandlerRaw`에 전달되지 않던 문제를 해결했습니다.
    *   `SetHostKeyHandler()` fallback을 추가하여 host 환경에서도 F10/F12 리셋이 정상 동작합니다.
*   **ROM 이미지 손상 버그 수정**:
    *   `WrZ80()`가 IPLK 상태와 무관하게 전역 `ROM[]` 미러에 쓰던 버그를 수정했습니다. 테이프 로딩 중(IPLK=0) ROM 이미지가 손상되어 RESET 시 Z80이 쓰레기 코드를 실행하며 멈추는 현상을 해결했습니다.
    *   `spcsys.IPLK == 1`일 때만 ROM 미러를 동기화하도록 조건을 추가했습니다.
*   **터보 로더 속도 최적화**:
    *   카세트 모터 작동 중(`spcsys.cas.motor`가 ON일 때) 스레드 대기 방식을 `MsSleep(1)` 대신 `Yield()` 방식으로 조절하여, CPU 자원을 에뮬레이터에 집중시킴으로써 1초 이내의 초고속 로딩을 완성했습니다.
*   **부트 최적화**:
    *   VCHIQ 사운드 및 USB 초기화를 `BOOT_INIT_FRAME`(400프레임) 이후로 지연시켜 첫 화면이 즉시 표시되도록 했습니다.
    *   EMMC/SD 카드 초기화, `LoadTapeConfig()`, `Cassette::loaddir()`를 `frame == 1` 시점으로 지연시켜 첫 프레임 렌더링을 더욱 앞당겼습니다.

### 3. OSD(On-Screen Display) 및 디버그 출력
*   **OSD 테이프 파일명 표시**:
    *   `ALT+LEFT`/`ALT+RIGHT`로 테이프 전환 시 현재 파일명을 화면 상단에 3초간 표시합니다.
    *   zip 파일의 경우 zip 파일명을 표시하고, 로딩 시작 시 내부 파일명을 1초간 표시합니다.
    *   테이프 끝에 도달하여 자동으로 되감길 때 내부 파일명을 1초간 표시합니다.
    *   OSD x 시작 위치를 0px로 조정하고, 40자로 잘라서 줄 넘김을 방지합니다.
    *   OSD 활성화 시 MC6847 화면 복사에서 OSD 행(y=2~13)을 건너뛰고, 이전 문자열 잔상을 검은색으로 지웁니다.
*   **진행 바 (Progress Bar)**:
    *   화면 맨 아래(y=236~239) 4px 높이의 가로 바로 현재 테이프 위치를 표시합니다.
    *   밝은 회색 = 전체 길이, 어두운 회색 = 현재 위치 (`pos / total` 비율).
    *   모터 ON 중에는 계속 표시되고, 모터 OFF 후 1초 뒤에 사라집니다.
*   **Host 디버그 로그**:
    *   Host 빌드에서 `ScreenLog()`가 stderr로 출력되어 RESET, MOTOR ON/OFF, 테이프 헤더 정보 등을 실시간 확인할 수 있습니다.

### 4. Zip 파일 로딩 개선
*   **Zip 내 모든 파일 로딩**:
    *   `loadzip()`에서 첫 번째 파일만 로드하고 `break`하던 것을 `continue`로 변경하여 zip 내 모든 `.tap`/`.cas` 파일을 순차적으로 테이프 버퍼에 이어 붙입니다.
    *   개별 파일 추출 실패 시 루프를 중단하지 않고 다음 파일로 넘어갑니다.
    *   `.cas` 비트 변환 시 버퍼 경계 계산을 `TAPE_SIZE - l - 1`로 수정하여 여러 파일 이어 붙이기 시 오버플로우를 방지합니다.
*   **Zip 파일명 보존**:
    *   `Cassette` 클래스에 `m_zip_name` 필드와 `is_zip()`/`get_zip_name()` 메서드를 추가하여 zip 원본 파일명을 별도로 보존합니다.
    *   `load()`에서 zip 확장자일 때 `m_zip_name`에 원본 파일명을 저장하고, `loadzip()`이 내부 파일명으로 `loaded_filename`을 덮어씁니다.

### 5. 하드웨어 주변기기 드라이버 통합
*   **SD 카드/FatFS 연동**: EMMC 드라이버를 초기화하고 SD 카드를 `SD:` 마운트하여 필요한 파일 시스템 로딩 구조를 확보했습니다.
*   **PSG 사운드 출력**: emu2149 PSG 코어 및 `CSPCSoundDevice`를 VCHIQ 사운드와 직접 연결하여 오디오 렌더링을 구현했습니다.
